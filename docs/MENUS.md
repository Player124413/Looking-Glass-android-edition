# Original menus and controls

Ordinary launch opens the original main menu directly, with no Continue/New visit overlay. **New Game** opens the original difficulty selector and opening film; **Load/Save** restores an existing slot. Before a game is running, Back to game and Save are hidden, replacement confirmations are skipped, Escape stays in the main menu, and quitting does not create or replace a save. Explicit `--map`, `--load`, `--new-game`, previews and frame-limited test runs retain direct launch behavior.

Press **Escape** during play to open the original main menu. Choose **Settings** for video, audio, controls or game options. Escape returns to the previous page; at the main menu it resumes the game. **Back to game** does the same. Escape closes the console, inventory or level chooser first if one of those is open. **F3** opens the original audio page directly.

Use the mouse, or **Up/Down** to select, **Enter** to activate, and **Left/Right** to change a value. On the Settings illustration, **1/2/3/4** select Video/Audio/Controls/Game. Volume, sensitivity and camera-distance sliders support clicking and dragging. **Apply** keeps and saves edits; **Cancel** or Escape discards unapplied edits. Gameplay and its audio are paused while the menus are open.

The **Tab** level selector follows the 39-visit story order, with names, map IDs and separate return rows at positions 5, 8 and 28. **Up/Down** selects, **Home/End** jumps to the first/last, **D** chooses difficulty and **Enter** starts that visit fresh at its correct entrance.

Windows Xbox/XInput controllers work throughout the menu: D-pad or left stick to browse, A to select, B to go back and Left/Right to adjust settings. Start opens the main menu from play. Menu controls stay fixed when gameplay bindings change.

## Tab chapter chooser

**Tab** opens the 39 story-ordered visits from either the main menu (including startup) or gameplay, including separate return entrances. Use the **mouse wheel** to scroll three rows per notch, **click** a row to select it, then **double-click** that row or click **Begin** to start a fresh visit with its campaign loadout. Rows stay still when selected with the mouse. Scrolling is bounded at both ends and keeps the chosen visit visible. Click the difficulty label to cycle the four difficulties; click **Return** (or press Tab/Escape) to go back to the screen that opened the chooser without loading a chapter. From the main menu, this returns to the main menu; from gameplay, it returns to the game.

On a controller, **Back/View** opens chapters, **D-pad / left stick** browses, **Y** changes difficulty, **A** begins the selected visit and **B** returns.

**Up/Down**, **Home/End**, **Enter**, **D**, and **Tab/Escape** retain their keyboard functions. The parchment, original lettering and arrow markers use the same scaled coordinates for drawing and clicking. Mouse input while the chooser is open does not turn Alice, cycle weapons or fire attacks. Chapter starts keep the existing fresh-visit behavior; they do not restore a saved campaign.

## Connected actions

- **New Game:** original Easy/Medium/Hard/Nightmare selector; replacing a running session also asks for confirmation. Plays the original opening film and soundtrack, then starts `gvillage` with the chosen difficulty and a fresh campaign. **P / controller Start** pauses the film; hold **Enter / A** to skip. Losing focus pauses both picture and sound. The current living session is automatically saved before replacement; existing quick saves are retained. See [cutscene support](CUTSCENE-AUDIT.md).
- **Load/Save:** the original camera/book artwork, all six original slot positions now work: four manual slots, quick save and autosave. Select a slot thumbnail or its button, then **Save** or **Load**. Empty manual slots save immediately; occupied slots ask before replacement. Autosave is reserved for progression and clean quit. Loading either slot uses the full existing restoration path, including backup recovery, and leaves the restored game paused. No original binary save files are imported. Missing or incompatible saves display an error without replacing the running session.
- **Quit:** the original Hatter confirmation screen. Yes exits through the existing automatic-save and cleanup path. No or Escape returns to the main menu. Credits uses original archive text/art with Previous/Next paging.
- **Video:** the original parchment, Asrafel lettering, Video title and Apply/Cancel artwork frame two arrow selectors. ## Original-data boundaries

The Load/Save camera now draws photographs **behind** the archive's ornate frames instead of painting rectangular cards over them. The selected photograph uses the original five-frame, 10 Hz sepia/scratch layer and blend factors. Its wooden shutters close in 180 ms, switch pictures at 350 ms and reopen after 500 ms, following the authored layout timing. Original projector, hover and button sounds use the existing audio output and effects/mute settings while the game stays paused. Slot names sit beside their brass selectors; the camera's plates show the chapter name and save date (UTC), or the focused Load/Save action. The original aperture and slot/button coordinates remain proportional on widescreen displays.

All six existing slots, saved screenshots, legacy/no-image fallbacks, backup recovery, confirmations and mouse/keyboard/controller actions retain their existing behavior. The artwork for the single page and inactive delete control is present; this visual restoration does not add deletion or extra save pages. Confirmations retain the current camera screen behind the dialog. No save-format change is needed.

The menus read `ui/main.urc`, `ui/controls.urc`, `ui/newgame.urc`, `ui/loadsave.urc`, `ui/quit.urc`, `ui/credits.urc`, their referenced texture/material assets, and the Asrafel bitmap font from the user's mounted archives. Main-menu hit rectangles and original button highlights are retained. Alice's mirror uses the authored `idle_stand_rocktoes` animation with intact surfaces and the shared skin renderer. Menu rendering adds no separate material pipeline per page or level.

The runtime parses layout data and routes an explicit set of Rust actions. Original `stuffcommand`, cvar, engine-restart and executable commands are never executed. The supported settings pages are adapted to this renderer; legacy Miles/EAX driver selection, 16-bit modes, gamma/detail controls, original binary saves/deletion and decorative transitions/sounds outside Load/Save are not reproduced. The original main menu and options are available at startup and in-game. Chapter selection shares its navigation and original parchment/lettering between both contexts. Settings use original checkbox and slider/arrow artwork, the original cursor and a shared archive-font renderer. See [UI_FIDELITY.md](UI_FIDELITY.md) for the gameplay overlays and remaining presentation differences.

## Checks

Native Anode checks use `private/menu-native` saves and `private/menu-test-settings` preferences, separate from the player's files. They cover opening/resuming with Escape, keyboard navigation, mouse slider input, Apply/Cancel, binding capture, fullscreen, save confirmation, repeated saves while paused, menu loading and New Game at the village entrance. The repeated-save check compares the complete gameplay payload, including resources, actor state, quests and clocks; it is unchanged while the menu is open. Unit checks cover layout bounds, widescreen hit testing, Escape hierarchy, preference validation and binding conflicts. Additional restart and final visual checks are recorded in `VALIDATION.md`.

## Launch-menu polish (2026-10-01)

The front end runs before any level or campaign is created. Chapter browsing and cancel/quit cannot advance world clocks or overwrite a checkpoint. The main menu retains its authored buttons, with a discreet Tab shortcut. Selecting a chapter starts that visit directly; New Game alone plays the opening film. Keyboard, pointer and controller chapter navigation share the same implementation as the in-game chooser.
