# Steam guide

The first guide is prepared as an unpublished draft for the repository owner to
review. It introduces Looking Glass as an experimental independent engine for
American McGee's Alice, hosted in the related Madness Returns community.

Its sections cover the project, practical benefits, download/setup, controls and
saves, preview limitations, troubleshooting and contributing. Public links point
to [skulitom/LookingGlass](https://github.com/skulitom/LookingGlass) and
[v0.32.0-preview.1](https://github.com/skulitom/LookingGlass/releases/tag/v0.32.0-preview.1).
The cover uses a real frame from the recorded preview, not a promised feature or
an original-game screenshot presented as Looking Glass.

Keep installation instructions aligned with [INSTALL.md](INSTALL.md). No separate
extractor or compiler is required for the Windows binary package. Do not call this
an official release, a completed remaster or a patch to Madness Returns. Keep
[known limitations](KNOWN_ISSUES.md) visible before the download instructions.

The user's reference guide supplies a format example only; the new wording is
independent. Publishing the Steam draft is a separate owner action.
