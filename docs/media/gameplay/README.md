# Gameplay recordings

Recorded on 1 October 2026 from the Windows preview, using ordinary controller
and keyboard input in a separate session with isolated saves. These are short
gameplay excerpts, not evidence of completing these levels. No cheats, staged
combat fixtures or generated frames were used.

| Video | Map | Length | What it shows |
| --- | --- | --- | --- |
| [Dry Landing](dry-landing.mp4) | `garden1` | 11.2 s | Cards combat against an ant guard |
| [Pool of Tears](pool-of-tears.mp4) | `potears1` | 10.3 s | Walking and looking around the waterfall path |
| [Pale Realm](pale-realm.mp4) | `wchess1` | 14.0 s | Exploring the chess town and fountain square |

The MP4 files use H.264, 1280 × 720, 30 frames per second, at normal speed.
Each is one continuous excerpt with only its beginning and end trimmed.
The looping GIFs show three seconds from those same recordings, reduced to
360 pixels wide and 8 frames per second for the README. No desktop, menus or
personal save data are included. Subtitles were disabled.

**These clips are silent.** The isolated recording session did not provide
an audio output. This is a capture limitation, not a statement about game audio.
