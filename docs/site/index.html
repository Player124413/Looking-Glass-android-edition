Allow 3 GB of free space for the game and setup.

  1. Download & extract

    Save the Windows ZIP using the button above. Right-click it, choose Extract All, and open the extracted LookingGlass folder.

  2. Open Launch.cmd

    Double-click Launch.cmd. The setup window opens on your first launch. Keep the entire extracted folder together.

  3. Set up & play

    Choose your compatible game folder or archive, or the optional download. Select Set up, then choose New Game when the game opens.

A few practical answers about the preview.

Report a problem
Is the whole game playable?

The full 39-visit campaign has completed automated native playthroughs, including one uninterrupted fresh run. This is still an experimental preview: cutscene staging, effects, materials and enemy behavior have known differences. Wider device and audible playthrough testing is unfinished.

Read the known issues and campaign testing notes for the exact coverage.

Which game files do I need?

The supported data is the English 2011 vanilla release of American McGee’s Alice. The engine download contains no original game data. Use files you are entitled to use.

Setup can select your existing folder or archive, or optionally download Alice1_2011_vanilla.7z from Internet Archive (about 933 MB). Compatibility with the 2000 retail release, other languages and texture modifications is not established. See where to get the files.

Is this an official remaster?

No. Looking Glass is an independent, unofficial recreation with a newly written engine. It uses the artwork, models, music and voices in your game files. It is not affiliated with or endorsed by Electronic Arts or the original creators.

Will my old saves work?

Looking Glass has its own save format. Saves from the original game cannot be imported. The preview includes manual slots, quick save and autosave. Use normal level exits to continue your campaign; selecting a chapter starts a fresh visit.

Can I play on Linux, Mac or Steam Deck?

The current tested package is for Windows x64. Other platforms are not certified. Contributions and careful compatibility reports are welcome.

Windows says the publisher is unknown. What now?

This preview is unsigned. Confirm that you downloaded it from the linked GitHub release, and check its source and checksum. Do not disable antivirus or system security. The troubleshooting guide covers launch and setup problems.
